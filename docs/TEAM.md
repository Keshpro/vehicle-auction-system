## Workflow
1. Clone the repository and switch to your personal branch.
2. Commit meaningful, working increments with descriptive messages.
3. Push and open a PR into `main`; link the assigned GitHub Issue.
4. Reviewer checks changes and tests before merging.
5. Pull `main` frequently to avoid conflicts.

Individual grading evidence: own authored commits, Issues, PR descriptions, code reviews, and demonstrated SQL features.
